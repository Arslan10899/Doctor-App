PythonAnywhere par latest update deploy karne ke liye:
(Console > Bash mein ek-ek command paste karo)

1) Doctor-App folder mein jao:
cd ~/Doctor-App

2) GitHub se latest code pull karo:
git pull origin main

3) Phir Web tab mein jao aur apna web app ke liye "Reload" button dabao

4) Browser mein hard refresh karo (cache saaf karne ke liye):
Ctrl + Shift + R
